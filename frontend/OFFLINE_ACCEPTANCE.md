# Ручная приёмка: работа без сети

Офлайн-режим (`public/sw.js`, `src/offline/`, описание — `docs/frontend.md`, абзац «Работа без сети»). Агенты телефон и браузер
не открывали: всё ниже — только на настоящем iPhone (Safari и приложение «На экран Домой») и, по возможности, Android Chrome.
Service worker работает только в production-сборке по HTTPS (сервер) либо на `http://127.0.0.1:5173` (`npm run build && npm run preview`).

## Подготовка

1. Открыть сайт с сетью, войти. Пройти экраны, которые нужны без сети: «Каталог», «Чеки», один чек, «Статистика»,
   «Добавить трату» (форма читает категории и умолчания — без сети она откроется, только если их уже читали).
2. Закрыть приложение полностью (смахнуть из переключателя приложений) и открыть снова — так service worker точно управляет страницей.

## Без сети

3. Включить авиарежим. Открыть приложение с экрана «Домой». Ожидается: приложение открывается (не «Safari не может открыть
   страницу»), сверху жёлтая полоса «**Нет сети.** Показаны сохранённые данные. Траты сохраним на телефоне…; фото можно
   отправить только при сети.» — в тёмной и в светлой теме (переключатель в шапке) текст читается.
4. Открыть «Каталог», «Чеки», чек из шага 1 — показываются сохранённые данные. Экран, который ни разу не открывали, — обычная
   ошибка «Не удалось связаться с сервером», приложение не падает.
5. Фото чека: «Загрузить фото» — отправка не удаётся с обычной ошибкой; в очередь фото не ставится (так задумано).
6. «Добавить трату»: сумма, категория, «Сохранить». Ожидается переход на «Чеки», сверху блок «Ждут отправки: 1» —
   «Сохранено на телефоне — отправим, когда появится сеть.», строка с местом, датой и суммой, кнопки «Исправить», «Удалить»,
   «Отправить сейчас».
7. Добавить вторую трату. «Отправить сейчас» без сети — строка «Сервер пока недоступен — отправим, когда появится сеть.», траты на месте.
8. «Исправить» у второй траты — форма открывается с её значениями; изменить сумму, «Сохранить» — в списке снова две траты,
   у второй новая сумма (старая запись заменена).
9. «Удалить» у второй траты — вопрос подтверждения, после «OK» в списке одна трата.

## Сеть вернулась

10. Выключить авиарежим, не закрывая приложение. Ожидается: в течение нескольких секунд блок «Ждут отправки» исчезает,
    полоса «Нет сети» пропадает после первого ответа сервера (например, обновить список потянув вниз или перейти по меню),
    в списке чеков — новая трата, ровно одна.
11. Повтор для отправки при старте: без сети добавить трату, закрыть приложение, включить сеть, открыть — трата отправлена.
12. Дубль при потерянном ответе (по возможности): включить «Network Link Conditioner» / очень плохую сеть, сохранить трату так,
    чтобы форма ответила «Сервер не ответил вовремя» и трата ушла в «Ждут отправки»; затем нормальная сеть — в списке чеков
    трата одна (если сервер её успел сохранить, повторно она не отправляется).
13. Ошибка сервера: трата, которую сервер отвергает (например, категория удалена в админке, пока трата ждала), остаётся в
    списке с текстом «Не отправлено: …»; её можно «Исправить» или «Удалить».

## Другой человек на том же телефоне

14. С сетью: выйти («Аккаунт» → «Выйти»), войти другим пользователем, включить авиарежим, открыть «Чеки» — данных первого
    человека нет (ошибка связи или только данные второго), его ожидающие траты не показываются и не отправляются от имени второго.

## Выкладка новой версии

15. С сетью открыть приложение, затем выложить новую версию (`deploy/docker/deploy.sh`). Свернуть приложение и вернуться
    в него — страница перезагружается сама и показывает новую версию (видно по изменению, ради которого выкладывали).
16. Закрыть приложение полностью и открыть с сетью — новая версия сразу. Без сети после выкладки — прежняя версия, при
    следующем открытии с сетью — новая.
17. Во время шага 15 держать открытой форму «Добавить трату» с введённой суммой — форма не перезагружается и введённое
    не теряется; после ухода с формы и возвращения в приложение — новая версия.

Запишите для каждого шага: прошло / не прошло (что видно) / не проверено и почему.
