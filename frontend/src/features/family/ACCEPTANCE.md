# Ручная приёмка: настройки, скрытые платежи, «Семья» (2026-10-12)

Режим `CHECKIST_AUTH_MODE=accounts`, пустая QA-база, телефон (360–430 px) и компьютер, обе темы. Агенты браузер не открывали.

## Настройки
1. `/account` → «Настройки»: видно имя и «Имя задаётся в админке»; список «Основная валюта» содержит все валюты сервера и «Не выбрана».
2. Выбрать KZT → сразу «Основная валюта — KZT.»; перезагрузить — значение осталось.
3. «Добавить трату» и «Лимиты» открываются с KZT; при чеках в двух валютах блок KZT на главной и в статистике — первый.

## Семья
4. Пользователь без семьи → «Ещё» → «Семья» → «Создать семью» → он главный (роль «главный · это вы»).
5. «Добавить человека» без пароля → пароль показан один раз, «Скопировать» копирует; после перезагрузки пароля нет. Войти новым человеком в другом браузере — он видит траты семьи.
6. Слабый пароль, занятый логин → сообщение «Проверьте: …», учётная запись не создана.
7. «Создать приглашение» → ссылка; открыть её под существующим пользователем без семьи (гость сначала входит) → «Вы в семье.». Повторное открытие той же ссылки другим → «Приглашение недействительно…». «Отозвать» убирает ссылку из списка.
8. «Сделать главным» у члена семьи → подтверждение в шторке → роли поменялись; прежний главный больше не видит «Добавить человека» и «Скрыть платёж».
9. Член семьи → «Выйти из семьи» → подтверждение → «Вы пока не в семье»; его чеки остались у него. Главный «Выйти» не видит; «Убрать из семьи» у члена — чеки остаются за человеком.

## Скрытые платежи
10. Главный: карточка траты → «Скрыть платёж» → шторка «Платёж пропадёт у всей семьи и не попадёт в суммы и лимиты» → подтвердить. Трата пропала из «Трат», суммы главной и статистики уменьшились.
11. «Траты» → чип «Показать скрытые» → трата с пометкой «скрыто»; карточка → «Показать платёж» возвращает её.
12. Член семьи: скрытая трата не видна нигде, её адрес — «не найдено»; чипа и кнопки нет.

## Несколько семей и ИИ (2026-10-13)
Сначала в `/admin/` → Users проверить, что у администратора сервера (на проде — `Suslicke`) стоит «Staff status».
13. Администратор → «Семья» → внизу «Новые семьи» → «Пригласить новую семью» → ссылка внутри карточки, «Скопировать». Обычный пользователь этой карточки не видит.
14. Открыть ссылку в чистом браузере (гость) → экран «Новая семья» с логотипом; пустая форма → поля отмечены; слабый пароль → правила пароля; занятый логин → «Проверьте: логин.»
15. Заполнить верно → «Создать семью» → сразу «Семья»: человек — главный, «Распознавание и подсказки ИИ» выключено, «Сегодня использовано 0 из 50». Ту же ссылку открыть ещё раз → «Приглашение недействительно…». Отозванная — тоже.
16. Открыть ссылку, будучи вошедшим → «Приглашение в новую семью… выйдите» → «Выйти» → та же страница показывает форму.
17. Новая семья (ИИ выключен): «Добавить трату» → «Скажите словами» → «ИИ выключен в вашей семье — включить может главный.»; «Снять чек» / загрузка фото → тот же текст; ничего не создано.
18. Главный включает переключатель → разбор и фото работают, «Сегодня использовано» растёт; член семьи видит «Включено» без переключателя.
19. Администратор ставит семье в `/admin/` → Households квоту 1 → второй разбор за сутки → «На сегодня запросы к ИИ закончились. Снова можно завтра в 05:00.» (полночь UTC — 05:00 в Алматы).
20. Старая семья (до выкладки) — ИИ включён и без предела: «Сегодня использовано N» без «из 50» и без полосы, много фото за день проходят.
21. Пользователь без семьи (не администратор сервера), например убранный из семьи, — «Скажите словами» и фото: «ИИ выключен…». Администратор сервера без семьи — работает.

## «Видит траты семьи с» (2026-10-13)
22. Главный → «Семья»: под каждым членом семьи «Видит траты семьи: с начала». Касание → лист → «Видит траты семьи» → выбрать сентябрь → лист закрылся, вверху «… видит траты семьи с сентября 2026.», строка под человеком изменилась.
23. Член семьи → «Семья»: ни строки, ни поля про месяц нет. «Траты» за август: только свои траты; чужая трата августа по прямому адресу — «не найдено». Статистика за август и «Динамика»: месяцы до сентября — только свои траты; Главная прошлого месяца — тоже. Свои старые траты видны все.
24. Главный видит всё как раньше. В листе выбрать «Без ограничения» → у члена семьи вернулась вся история.
25. Передать роль главного члену семьи с ограничением → у него ограничение снято (видит всё).
