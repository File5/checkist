## Фон

**Полный логотип** (`logo-source.png`, `logo-*.webp`) непрозрачный, фон — почти чёрный с шумом ±1–2 на канал. Медиана по рамке шириной 8 px со всех четырёх сторон: **`#0f0f0e`** (RGB 15, 15, 14; среднее 14,6 / 14,5 / 14,1). Это значение для токена `--ck-logo-bg`. Фон в прозрачность не вырезан: на светлой подложке вокруг логотипа будет ореол, поэтому его всегда ставят на подложку `--ck-logo-bg` (доска экрана входа).

**Эмблема** (`emblem-*.webp`) — с прозрачным фоном, подложка ей не нужна: в шапке она лежит прямо на полосе `--ck-header-bg`, тёмной в обеих темах. Внешний контур эмблемы чёрный, поэтому на светлом фоне она тоже читается, но там её никто не показывает.

Значку `apple-touch-icon.png` прозрачность нельзя: iOS заливает её чёрным. Он собран на подложке `#0f0f0e` и сохранён без альфа-канала.

Цвета, взятые с исходника логотипа для `favicon.svg`: красный звезды `#bd0109`, золото `#fcd36e`.

## Исходник эмблемы: фон в файле не прозрачный

`emblem-source.png` записан как RGBA, но альфа-канал у него сплошной (минимум и максимум — 255): вместо прозрачности вокруг рисунка лежит ровный чёрный `(0, 0, 0)` без шума — 691 580 пикселей из 1 572 516, из них 640 682 связаны с углами. Файл положен как получен, прозрачность восстановлена при сборке:

- фон — пиксели с точным значением `(0, 0, 0)`, до которых заливка (4-связная) доходит от четырёх углов; они получают альфу 0, остальные — 255;
- результат устойчив: при пороге «максимум канала ≤ 4» заливка захватывает те же области (641 329 пикселей), рамка содержимого та же — `(58, 5, 1193, 1228)`; при пороге 8 она уже протекает в чёрный контур, поэтому порог — точный ноль;
- чёрные участки внутри рисунка (сердцевины контуров, штрихкод, просветы между колосьями и щитом, не связанные с краем) остаются непрозрачными чёрными — отличить в файле фон от чёрной краски там нечем; при показе 40–44 px на тёмной полосе это часть контура.

Если владелец пришлёт файл с настоящим альфа-каналом, шаг заливки заменяется на `alpha = im.getchannel('A')`, остальное то же.

## Как получены

Pillow 12.3.0 (окружение backend), фильтр уменьшения — `Image.LANCZOS`. Скрипт в репозиторий не входит; ниже — всё, что нужно для повторения (запуск из корня репозитория).

Полный логотип:

```python
from PIL import Image
im = Image.open('frontend/brand/logo-source.png').convert('RGB')

# 1280 — небольшое увеличение исходника 1254 px.
im.resize((640, 640), Image.LANCZOS).save('logo-640.webp', 'WEBP', quality=82, method=6)
im.resize((1280, 1280), Image.LANCZOS).save('logo-1280.webp', 'WEBP', quality=82, method=6)
```

Эмблема и значок:

```python
from PIL import Image, ImageChops, ImageDraw
im = Image.open('frontend/brand/emblem-source.png').convert('RGB')

# Альфа: точный чёрный, связанный с углами, — фон.
r, g, b = im.split()
m = ImageChops.lighter(ImageChops.lighter(r, g), b).point(lambda v: 255 if v else 0)
w, h = im.size
for corner in [(0, 0), (w - 1, 0), (0, h - 1), (w - 1, h - 1)]:
    ImageDraw.floodfill(m, corner, 128)
alpha = m.point(lambda v: 0 if v == 128 else 255)

# Кадр по рамке содержимого (58, 5, 1193, 1228) = 1135×1223, в центре прозрачного
# квадрата со стороной 1223 + 2·24 = 1271: пропорции не искажены, поле сверху и снизу 24 px.
rgba = im.convert('RGBA'); rgba.putalpha(alpha)
cut = rgba.crop(alpha.getbbox())
side = max(cut.size) + 2 * 24
sq = Image.new('RGBA', (side, side), (0, 0, 0, 0))
sq.paste(cut, ((side - cut.width) // 2, (side - cut.height) // 2))

sq.resize((96, 96), Image.LANCZOS).save('frontend/src/assets/brand/emblem-96.webp', 'WEBP', quality=90, method=6)
sq.resize((192, 192), Image.LANCZOS).save('frontend/src/assets/brand/emblem-192.webp', 'WEBP', quality=90, method=6)

# Значок iOS: тот же квадрат на непрозрачной подложке #0f0f0e, RGB.
icon = Image.new('RGBA', (side, side), (15, 15, 14, 255))
icon.alpha_composite(sq)
icon.convert('RGB').resize((180, 180), Image.LANCZOS).save('frontend/public/apple-touch-icon.png', 'PNG', optimize=True)
```

Проверка результата: оба `emblem-*.webp` — режим RGBA, альфа от 0 до 255, угловой пиксель `(0, 0, 0, 0)`; `apple-touch-icon.png` — режим RGB, угловой пиксель `(15, 15, 14)`. Заголовки этих трёх файлов сторожит `frontend/src/theme/shell-css.test.ts`.

## История: прежняя эмблема (до 2026-10-08)

До замены эмблема вырезалась из полного логотипа: квадратный кадр `(160, 0, 1090, 930)` его верхней части, непрозрачный, с фоном `#0f0f0e`. Надпись под ней закрашивалась цветом фона вручную по измеренной кромке золотой линии, потому что остриё меча и лента заходили на надпись; в шапке под картинкой лежала подложка `--ck-logo-bg` со скруглением. С отдельным исходником эмблемы закраска и подложка не нужны; прежние файлы — в истории git (`emblem-96.webp` 4 800 байт, `emblem-192.webp` 14 052 байта, `apple-touch-icon.png` 56 164 байта).
