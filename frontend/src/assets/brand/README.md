## Фон

Исходник непрозрачный, фон — почти чёрный с шумом ±1–2 на канал. Медиана по рамке шириной 8 px со всех четырёх сторон: **`#0f0f0e`** (RGB 15, 15, 14; среднее 14,6 / 14,5 / 14,1). Это значение для токена `--ck-logo-bg`.

Фон в прозрачность не вырезан: на светлой подложке вокруг эмблемы будет ореол. Логотип и эмблему всегда ставить на подложку `#0f0f0e`.

Цвета, взятые с исходника для `favicon.svg`: красный звезды `#bd0109`, золото `#fcd36e`.

## Как получены

Pillow 12.3.0 (окружение backend), фильтр уменьшения — `Image.LANCZOS`. Скрипт в репозиторий не входит; ниже — всё, что нужно для повторения.

```python
from PIL import Image
im = Image.open('frontend/brand/logo-source.png').convert('RGB')

# Полный логотип. 1280 — небольшое увеличение исходника 1254 px.
im.resize((640, 640), Image.LANCZOS).save('logo-640.webp', 'WEBP', quality=82, method=6)
im.resize((1280, 1280), Image.LANCZOS).save('logo-1280.webp', 'WEBP', quality=82, method=6)

# Эмблема: квадратный кадр верхней части (после закраски, см. ниже).
sq = emblem.crop((160, 0, 1090, 930))  # left, top, right, bottom
sq.resize((96, 96), Image.LANCZOS).save('emblem-96.webp', 'WEBP', quality=90, method=6)
sq.resize((192, 192), Image.LANCZOS).save('emblem-192.webp', 'WEBP', quality=90, method=6)
sq.resize((180, 180), Image.LANCZOS).save('apple-touch-icon.png', 'PNG', optimize=True)
```

### Закраска под эмблемой

Чистым кадрированием эмблему от надписи не отделить: остриё меча (до y = 912) и нижний сгиб ленты заходят на золотую линию над словом «ЧЕКИСТ» (y = 837–886) и на верх букв (от y ≈ 859). Поэтому в копии исходника перед кадрированием закрашено цветом фона `#0f0f0e` всё, что ниже верхнего края золотой линии с запасом 3 px, кроме:

- острия меча — связная светлая область (максимум канала > 60) от точки (630, 880) ниже y = 836, расширенная на 4 px, чтобы сохранить тёмный контур;
- красного полотна ленты — пиксели с `r > 60 and g < 0.35 * r` выше y = 900.

Верхний край линии измерен по столбцам (x → y), между точками — линейная интерполяция:

```
130→836 140→837 175→843 210→848 245→852 280→857 315→861 350→864 385→867 420→870
455→872 525→872 560→876 700→876 805→873 840→870 875→867 910→863 945→860 980→856
1015→852 1050→847 1085→841 1121→836
```

Вместе с линией ушла тонкая золотая кромка нижнего края ленты там, где она сливается с линией (x ≈ 455–560 и 700–800). При показе 40–48 px и в значке 180 px это незаметно; для крупного показа эмблемы без надписи нужен отдельный исходник от автора.
