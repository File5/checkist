# Checkist

Перед работой обязательно прочитай [AGENTS.md](AGENTS.md) и относящиеся к задаче документы: [архитектуру](docs/architecture.md), [API-контракт](docs/api-contract.md), [разработку](docs/development.md), [проверки](docs/verification.md). Правила и команды находятся там; сверяй их с кодом.

Реализованы серверный scaffold и React/TypeScript/Vite SPA для настоящего health API через proxy; клиент описан в [docs/frontend.md](docs/frontend.md). Распознавание чеков, предметная модель, категории и дашборд планируются. Визуальную и интерактивную приёмку UI выполняет человек.
