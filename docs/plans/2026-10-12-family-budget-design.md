# Семейный бюджет: проект (2026-10-12)

Форк `Suslicke/checkist` превращает распознаватель чеков в инструмент семейного бюджета. Решения приняты с человеком 2026-10-12.

## Что получает человек

- Своя учётная запись у каждого члена семьи; все члены семьи видят и добавляют траты в один общий список. У траты видно, кто её добавил.
- Трата без чека: сумма и категория обязательны; дата (сегодня), место, комментарий и позиции — по желанию.
- Трата словами: «такси до аэропорта 4500» → Codex заполняет ту же форму, человек проверяет и сохраняет.
- Главный экран после входа — дашборд месяца: потрачено против прошлого месяца, лимиты по категориям с полосами прогресса, последние траты, большие «Снять чек» и «Добавить трату».
- Спокойный семейный вид: светлая тема по умолчанию, карточки, крупные цифры, цвета категорий. Имя «Чекист» и тёмная тема остаются.

## Порядок работ

Каждый шаг выкатывается на сервер отдельно и не ломает прежнее.

0. Форк `Suslicke/checkist`, сервер тянет из него — **сделано 2026-10-12**.
1. Семья.
2. Трата без чека (форма).
3. Трата словами (Codex).
4. Лимиты и дашборд.
5. Редизайн.

## 1. Семья

- Модель `accounts.Household` (название) и членство: у пользователя не больше одной семьи (`Membership`: user unique, household).
- Правило доступа одно — `accounts/access.py::owner_q`: «владелец — я» становится «владелец — член моей семьи». Пользователь без семьи видит только своё, как сейчас. `local_single` не меняется.
- `owner` остаётся и значит «кто добавил». Дедупликация чеков и `sha256` фото остаются в пределах владельца: одинаковый чек от двух членов семьи — пока две записи (решить, если станет мешать).
- Семью и членов заводит администратор в `/admin/`; экрана приглашений нет.
- Клиент: в списках и карточке чека — «добавил: имя».

## 2. Трата без чека (вариант А)

Трата без чека — это `Receipt`, а не новая таблица, чтобы списки, статистика и дашборд оставались одной выборкой.

- `Receipt.source`: `photo` | `manual` (прежние — `photo`). `Receipt.store` становится необязательным (`null` = «Без места»). Фискальные поля и так могут быть пустыми.
- `ReceiptLine.category` (FK на категорию, null): у строки без товара категория берётся из неё. Статистика (`receipts/spending.py`) берёт категорию товара, если товар есть, иначе — категорию строки.
- Ручная трата без позиций — одна строка «сумма в категории». С позициями — строки с названиями; сопоставление с каталогом — тем же механизмом, что при импорте (новые товары создаются автоматически).
- Три правила дедупликации чека к ручным тратам не применяются: два одинаковых кофе в один день — две траты.
- API: `POST /api/receipts/manual/`, правка и удаление своей семьёй — `PATCH` / `DELETE /api/receipts/{id}/` только для `source=manual`. Распознанный чек через API по-прежнему не правится.
- Клиент: «Добавить трату» — экран-форма, оптимизирована под телефон (сумма с цифровой клавиатурой, чипы частых категорий).

## 3. Трата словами

- `POST /api/receipts/manual/parse/` принимает текст и возвращает черновик формы (сумма, валюта, категория, дата, место, позиции). Ничего не сохраняет.
- Исполнение — текстовый вызов Codex (как `classification`, без изображения) либо fake. Сбой или таймаут — понятный текст; форма остаётся для ручного ввода.
- Codex живёт в контейнере `recognition`, а не в `web`: синхронный вызов из `web` либо очередь как у распознавания (задача → опрос) — решить в плане шага 3.

## 4. Лимиты и дашборд

- `budget.BudgetLimit`: семья (или пользователь без семьи), категория верхнего уровня, валюта, сумма в месяц. Правка — на экране лимитов.
- `GET /api/dashboard/?month=YYYY-MM`: итог месяца и прошлого по валютам, по категориям — потрачено и лимит, последние 10 трат. Валюты не складываются, как во всей статистике.
- Клиент: `/` и переход после входа — дашборд вместо каталога. Каталог и прежняя статистика остаются в меню.

## 5. Редизайн

- Новые значения токенов в `frontend/src/theme/tokens.css`: светлая тема по умолчанию, спокойная палитра, цвета категорий. Правила проекта о токенах, `nowrap` и мобильной раскладке сохраняются.
- Нижнее меню телефона: «Главная · Траты · ＋ · Статистика · Ещё», где «＋» — добавить трату / снять чек. Плавающая «Снять чек» уходит в меню.
- Шутки («Совершенно несекретно», «Доверяй, но проверяй чек») уходят во второй план.
